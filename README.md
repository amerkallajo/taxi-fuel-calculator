# 🚕 حاسبة مصروف التكسي

حاسبة بنزين باللغة العربية للآيفون، تعمل كتطبيق من الشاشة الرئيسية، وتستخدم ملفات محلية بعد التثبيت لتعمل بدون إنترنت.

## تشغيل الموقع مرة واحدة

1. من GitHub افتح **Settings → Pages** للمستودع.
2. في **Build and deployment** اختر **Deploy from a branch**.
3. اختر **main** و **/(root)** ثم اضغط **Save**.
4. افتح الرابط التالي في Safari: https://amerkallajo.github.io/taxi-fuel-calculator/
5. تأكد أن الحاسبة تعمل، ثم اضغط زر المشاركة في Safari، واختر **Add to Home Screen / إضافة إلى الشاشة الرئيسية**.
6. افتح الأيقونة الجديدة وأنت متصل بالإنترنت للمرة الأولى؛ انتظر تحميل الصفحة ثم جرّب وضع الطيران وأغلق التطبيق وافتحه مرة أخرى.

## الوظائف

- حساب لتر البنزين المستهلك حسب المسافة (كم) والكفاءة (Km/L).
- حساب التكلفة حسب سعر لتر البنزين والعملة.
- خيار احتساب الرجعة أيضاً.
- عرض تكلفة الكيلومتر الواحد ونسخ نتيجة الرحلة.
- تخزين سعر اللتر وكفاءة السيارة والعملة محلياً على الآيفون فقط.

**المعادلة:** تكلفة البنزين = (مسافة المشوار ÷ عدد الكيلومترات لكل لتر) × سعر اللتر.

## تشغيل بدون إنترنت

ملف `sw.js` يخزّن صفحة الحاسبة والملفات الأساسية عند أول زيارة بنجاح عبر HTTPS، بحيث لا يلزم الإنترنت للاستخدام اليومي. لا يحتاج التطبيق إلى حساب أو تسجيل دخول، ولا يرسل بيانات السيارة إلى خادم.

> ملاحظة: حذف بيانات المواقع أو التطبيق من الآيفون قد يحذف البيانات المخزنة، وقد يتطلب تحميله عبر الإنترنت مرة ثانية. وفي المرة الأولى اختبر العمل في وضع الطيران.
