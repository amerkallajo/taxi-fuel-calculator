# 🛣️ حاسبة تكاليف الطريق — Road Cost

حاسبة عربية مجانية ومفتوحة للجميع لحساب **تكلفة وقود السيارة** أثناء المشاوير والرحلات، مع واجهة داكنة وأيقونة خاصة بالطريق، وتعمل بدون إنترنت بعد أول تحميل ناجح.

## افتح الحاسبة

**https://amerkallajo.github.io/taxi-fuel-calculator/**

لا حاجة إلى حساب أو تسجيل دخول، وتُحفظ إعدادات الاستهلاك وسعر البنزين والعملة محلياً على الجهاز.

## ماذا تحسب؟

- المسافة بالكيلومتر، مع إمكانية احتساب الذهاب والرجعة.
- كفاءة استهلاك الوقود بوحدة **كم/لتر (Km/L)**.
- كمية الوقود اللازمة للرحلة باللتر.
- تكلفة البنزين للرحلة وتكلفة كل كيلومتر.
- نسخ النتائج ومشاركتها.

**المعادلة:** تكلفة البنزين = (مسافة الرحلة ÷ كيلومترات لكل لتر) × سعر اللتر.

**ملاحظة مهمة:** الحاسبة حالياً تحسب **الوقود فقط**، ولا تشمل رسوم الطرق أو أجرة السائق أو الصيانة أو استهلاك السيارة.

## تثبيت الحاسبة للاستخدام دون إنترنت

**iPhone (Safari):** افتح الرابط في Safari → زر المشاركة → **إضافة إلى الشاشة الرئيسية / Add to Home Screen** → فعّل **Open as Web App** إذا ظهر ثم اضغط إضافة. افتح التطبيق وأنت متصل بالإنترنت أول مرة، وبعد اكتمال التحميل اختبر وضع الطيران.

**Android (Chrome):** افتح الرابط في Chrome → قائمة النقاط الثلاث ⋮ → **تثبيت التطبيق / Install app** أو **إضافة إلى الشاشة الرئيسية / Add to Home Screen** حسب الجهاز والمتصفح. افتح التطبيق أول مرة وأنت متصل بالإنترنت، ثم اختبر تشغيله أوفلاين.

قد يحتفظ النظام بالأيقونة القديمة بعد تحديث الهوية؛ قد تحتاج إزالة اختصار الشاشة الرئيسية وإضافته من جديد لتظهر الأيقونة الجديدة. لا تحذف بيانات المتصفح أو الموقع إذا أردت الحفاظ على الإعدادات المخزنة.

## تنفيذ المشروع

واجهة HTML/CSS/JavaScript بدون حسابات مستخدم. الحاسبة اليدوية مستقلة عن خدمات الخرائط الخارجية. يدير Service Worker تخزين ملفات الصفحة لتشغيلها بدون إنترنت. المشروع مستضاف على GitHub Pages، ويمكن تصفح الكود من GitHub.


## البحث بالخريطة وحساب طريق السيارة

افتح قسم «احسب المسافة على الخريطة»، اختر نقطة الانطلاق عبر زر GPS (بإذن صريح) أو بالبحث أو بالضغط على الخريطة، ثم حدد الوجهة واضغط «احسب الطريق». تعرض OSRM **مسافة القيادة الفعلية على شبكة الطرق** ومدة تقديرية دون معلومات مرور مباشرة. تُنقل مسافة **الاتجاه الواحد** إلى الحاسبة، وتظل مضاعفة «الذهاب والرجعة» ضمن حسابات الحاسبة الحالية. يمكنك تغيير المسافة يدوياً دائماً.

**اختيار المواقع والبحث:** ابحث عن الانطلاق أو الوجهة بالعربية أو الإنجليزية واضغط **بحث**؛ تُعرض النتائج للاختيار صراحةً ولا يختار زر حساب الطريق أول نتيجة تلقائياً. يمكن دائماً اختيار أي نقطة بالنقر على الخريطة حتى لو توقفت خدمات البحث. الإحداثيات المختارة تُستخدم مباشرة في OSRM، ولا يعتمد حساب الطريق على خدمة البحث بعد اختيار الموقع.

**مزودو البيانات والخصوصية:** البحث المباشر يستعمل [Nominatim العام](https://operations.osmfoundation.org/policies/nominatim/) لطلبات العربية و[Photon demo](https://github.com/komoot/photon#demo-server) للإنجليزية مع خيار بديل عند فشل المزود الأول أو عدم وجود نتائج. يتم إرسال **عبارة البحث فقط عند ضغط زر البحث أو Enter** وليس خلال الكتابة، وتُرسل إحداثيات نقطتي الرحلة إلى [OSRM demo](https://github.com/Project-OSRM/osrm-backend/wiki/Demo-server) عند حساب الطريق، وتُحمّل مربعات خريطة OpenStreetMap الظاهرة فقط مع [الإسناد اللازم](https://www.openstreetmap.org/copyright). لا يتم تخزين إحداثيات الرحلة في localStorage؛ تحتفظ الحاسبة بمفتاح إعداداتها القديم وتُحفظ آخر **مسافة ومدة فقط** في مفتاح مستقل.

**شروط Nominatim العامة مهمة:** [سياسة الاستخدام الرسمية](https://operations.osmfoundation.org/policies/nominatim/) تمنع الإكمال التلقائي وتضع سقفاً صارماً مقداره **طلب واحد في الثانية للموقع/التطبيق ككل وليس لكل هاتف**، وتلزم تعريف التطبيق عبر Referer أو User-Agent وإظهار المصدر وتوفير القدرة على نقل الخدمة. لذلك لا يوجد بحث أثناء الكتابة وتوجد مهلة محلية وكاش للاستعلامات خلال الجلسة. **هذا الكود لا يمكنه فرض حد عالمي عبر جميع مستخدمي GitHub Pages**؛ الملاءمة هنا مشروطة باستخدام منخفض جداً، ولا يُعد ضماناً للإنتاج عند انتشار التطبيق. عند زيادة المستخدمين يجب نقل البحث إلى مزود مستضاف ذي حصة معروفة أو Proxy ذي rate-limiting مركزي، أو استضافة Nominatim/Photon ذاتياً. Pelias خيار مفتوح المصدر للاستضافة الذاتية، لكن ليس هناك مزود Pelias عام مجاني مضمون دون API Key. لا تضع مفتاح API سرياً في JavaScript المنشور. تكاليف الاستضافة تختلف حسب الحجم وعدد الاستعلامات وتُحدد عند اختيار العرض الفعلي، ولا تُفترض رسوم أو اشتراكات قبل ذلك.

**حدود الخدمة:** كل من Photon وOSRM وNominatim العامة خدمات خارجية تطوعية يمكن أن تتوقف أو تقيّد الاستعلامات. أي HTTP 403/429/5xx أو Timeout ينعكس على رسالة الخطأ، وتبقى النقاط على الخريطة مستقلة عن البحث. اختبارات CI تقسم الاختبارات المحاكية والطلبات الحية، ولا تعتبر نجاح CI ضماناً لوصول الخدمة على كل الشبكات. فحص WebKit يحاكي محرك Safari وليس اختباراً على iPhone حقيقي.

**بدون إنترنت:** تظل الحاسبة اليدوية وبيانات السيارة متاحة بعد تثبيت PWA. لا تُحسب مسارات جديدة دون الإنترنت ومحرك توجيه متاح؛ أحياناً يمكن للمتصفح عرض أجزاء من الخريطة المخزنة مسبقاً، لكن لا توجد خرائط أو توجيه Offline مضمونان. عند عدم إيجاد مسار لا يجري استخدام Haversine أو تقدير بخط مستقيم.
